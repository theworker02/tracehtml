# tracehtml

Trace host/html network string helpers for config audits.

**Site:** https://theworker02.github.io/tracehtml/

## Install / run

```bash
git clone https://github.com/theworker02/tracehtml.git
cd tracehtml
node src/cli.js
node --test
```
